# 🎵 简谱音乐播放器

> **新版：`songbook.html`** —— 照着歌谱抄数字，分段落（主歌、副歌……），勾选想播的段落、排好顺序，一键按顺序播放；播放时歌谱和琴键会跟着亮。写法见下面“新版歌谱写法”。旧版（`index.html`，按秒数）仍然保留。

### 新版歌谱写法

- 数字：`1`~`7`；`.1` 低音（数字下面的点）、`1*` 或 `i` 高音（数字上面的点）、`#4` 或 `4#` 升半音（数字前面的 ♯）。
- 一拍：`1`　半拍（数字下面一道线）：`1_`　四分之一拍（两道线）：`1__`
- **下划线的几个音用括号**：`(5 6)` 每个半拍，`((5 6))` 每个四分之一拍；数字可以连着写不用空格：`0 (56)(54)(34)`。
- 拖长（数字后面的横杠）：`1 -` 是 2 拍，`1 - - -` 是 4 拍；`-_` 再多半拍。
- **附点（数字右边的点）**：`5.` 比原来长一半。点后面要空一格再写下一个音。
- 连音线（两个一样的音连成一个长音）：`2 ~ 2`。
- 停顿：`0`（一拍）、`0_`（半拍）；小节线 `|` 只是方便对照，不影响播放。
- **调**：谱子左上角写 “F major” 就在页面选 `1 = F`；太高或太低可以用“升降半音”整首移调。
- **反复、1./2. 结尾**：把每一段分开写，然后在“播放顺序”里排（比如 前段 → 后段·歌词1 → 前段 → 后段·歌词2）。
- **和弦（数字上面的 F、C、Gm、B♭、C7…）**：写在要换和弦的那个音前面，用花括号：`{F} 0 (56)(54)(34)`。字母一直管到下一个字母出现。播放时旋律下面会垫着弹伴奏（可关），蓝色的琴键就是和弦要同时按的键；页面上要选对“拍号”（4/4、2/4…）。
- **音色**：旋律和伴奏可以分别选。内置 10 种（钢琴、电钢琴、管风琴、吉他、竖琴、小提琴、弦乐、长笛、八音盒、电子），是电脑合成的；带 🌐 的是真实乐器录音（FluidR3 音色库），要联网，第一次下载 1~3 MB。
- **拍照识谱（实验）**：页面里有“📷 拍照识谱”，可以连你电脑上的 Ollama，选一张歌谱照片，让几个能看图的模型各读一遍，对比后把结果填进歌谱。小模型不一定看得懂简谱，一定要播放听一遍核对。
- 速度填歌谱上的“每分钟几拍”；歌词可选，一个字对一个音，某个音没字就写 `_`。
- 播放时歌谱会亮起来，琴键也会跟着亮，并显示“现在按：F4”。
- “我的歌曲”里可以保存、导出、导入（合并）；“载入我的歌谱本里的歌”会放进 4 首：《天主住在我心中》《你是》《我将见我慈母》《奉献圣母》。

一个打开浏览器就能用的小工具：点琴键或输入数字，就能写出一段旋律并播放出来。

## 怎么用

1. 用浏览器打开 `index.html`（双击即可，不需要安装任何东西）。
2. **先打音：** 点琴键（先选低音／中音／高音，黑键是升半音）。也可以直接在文字框里打字，格式见下面。
3. **再定长短：** 点旋律里的小方块选中音（可以点好几个，按住 Shift 点两个能选中间一整段），再点“短／中／长／超长”，或填自己的秒数。刚打的音会自动选中，直接点长短就行；只选一个音时，定完会自动跳到下一个没定长短的音，可以连着点。
4. 点 **▶ 播放**。想中途停下，点 **■ 停止**。

没定长短的音显示成虚线的“?”，播放时先按半秒算。

页面上还有：
- **改音：** 只选一个音时，可以改它是哪个音、高低、升半音；**删除选中的** 可以一次删掉好几个；
- **加停顿**、**删掉最后一个**、**全部清空**；
- **速度、音量** 滑块，和 **柔和／纯净／电子** 三种音色；
- **试听例子**：《小星星》《生日快乐》《玛丽有只小羊羔》；
- 播放时，当前播到的音会亮起来；写错的音显示成红色并有提示；
- 你写的旋律会自动保存在浏览器里，关掉再打开还在。

## 保存、导出、导入、合并

- **保存：** 起个名字点“保存”，歌存在这台电脑的浏览器里；列表里可以“打开”、“接在后面”（接到现在的旋律后面）、“导出”、“删除”。
- **导出：** “导出全部”会下载一个文件，可以当备份，也可以发给别人。
- **导入（合并）：** 选一个导出的文件，歌会合并进现有的歌里，不会覆盖你已有的：
  - 名字和内容都一样的，跳过；
  - 名字一样但内容不同的，另存为“名字（导入）”，两首都保留；
  - 新的歌直接加进来。

## 打字的写法

每个音写成 `音:秒数`，用空格隔开。例如：

```
1:0.5 1:0.5 5:0.5 5:0.5 6:0.5 6:0.5 5:1
```

| 写法 | 意思 |
| --- | --- |
| `1` ~ `7` | do re mi fa sol la si（中音） |
| `.1` | 前面加点：低音 |
| `1*` | 后面加星：高音 |
| `1#` | 后面加井号：升半音（`1#`、`2#`、`4#`、`5#`、`6#` 都可以） |
| `0:0.5` | 停顿半秒 |
| `Tempo:2` | 速度 2 倍，数字越大越快。写了它就以它为准，不看滑块 |

秒数越大，这个音越长。
