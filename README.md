# 🎵 简谱音乐播放器

一个打开浏览器就能用的小工具：点琴键或输入数字，就能写出一段旋律并播放出来。

## 怎么用

1. 用浏览器打开 `index.html`（双击即可，不需要安装任何东西）。
2. **先打音：** 点琴键（先选低音／中音／高音，黑键是升半音）。也可以直接在文字框里打字，格式见下面。
3. **再定长短：** 点旋律里的小方块选中音（可以点好几个，按住 Shift 点两个能选中间一整段），再点“短／中／长／超长”，或填自己的秒数。刚打的音会自动选中，直接点长短就行；只选一个音时，定完会自动跳到下一个没定长短的音，可以连着点。
4. 点 **▶ 播放**。想中途停下，点 **■ 停止**。

没定长短的音显示成虚线的“?”，播放时先按半秒算。

页面上还有：
- **改音：** 只选一个音时，可以改它是哪个音、高低、升半音；**删除选中的** 可以一次删掉好几个；
- **加停顿**、**删掉最后一个**、**全部清空**；
- **速度、音量** 滑块，和 **柔和／纯净／电子** 三种音色；
- **试听例子**：《小星星》《生日快乐》《玛丽有只小羊羔》；
- 播放时，当前播到的音会亮起来；写错的音显示成红色并有提示；
- 你写的旋律会自动保存在浏览器里，关掉再打开还在。

## 保存、导出、导入、合并

- **保存：** 起个名字点“保存”，歌存在这台电脑的浏览器里；列表里可以“打开”、“接在后面”（接到现在的旋律后面）、“导出”、“删除”。
- **导出：** “导出全部”会下载一个文件，可以当备份，也可以发给别人。
- **导入（合并）：** 选一个导出的文件，歌会合并进现有的歌里，不会覆盖你已有的：
  - 名字和内容都一样的，跳过；
  - 名字一样但内容不同的，另存为“名字（导入）”，两首都保留；
  - 新的歌直接加进来。

## 打字的写法

每个音写成 `音:秒数`，用空格隔开。例如：

```
1:0.5 1:0.5 5:0.5 5:0.5 6:0.5 6:0.5 5:1
```

| 写法 | 意思 |
| --- | --- |
| `1` ~ `7` | do re mi fa sol la si（中音） |
| `.1` | 前面加点：低音 |
| `1*` | 后面加星：高音 |
| `1#` | 后面加井号：升半音（`1#`、`2#`、`4#`、`5#`、`6#` 都可以） |
| `0:0.5` | 停顿半秒 |
| `Tempo:2` | 速度 2 倍，数字越大越快。写了它就以它为准，不看滑块 |

秒数越大，这个音越长。
